I added the "get_z_field_container" function to assembler.hpp and assembler_def.hpp in order to exact the optimal solution in field container form. This is needed to compute the gradient of the objective with respect to the parameters evaluated at the optimal solution.

I added the "setParameter" function to ROL_DynamicConstraint.hpp, ROL_DynamicObjective.hpp, ROL_ReducedDynamicObjective.hpp, and dynconstraint.hpp. This is needed to update the parameters in the PDE.

I put hessian finite differences in dynconstraint.hpp as a default if they are not provided. As of February 11, 2022 I stopped maintaining this modification as it is unnecessary work each time ROL changes.

I modified the "setParameter" function in dynpde.hpp to make it virtual. This was necessary for parameter updates in the dynamic constraint.

I created the file ROL_ReducedDynamicObjective_Stationary_Control.hpp to solve problems with transiant dynamics and stationary optimization variables.

I created the files ltiobjective_TS.hpp, Misfit_Regularization_TS_Objective_SimOpt.hpp, and Objective_SimOpt_TS.hpp to enable inverse problems with sparse data in the dynamic constraint.
